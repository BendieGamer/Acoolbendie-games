HOW IT WORKS: Three client-side probes run in parallel — (1) an unsandboxed hidden iframe that browser filter extensions (Lightspeed, GoGuardian, Securly, etc.) can intercept; if the iframe navigates to a chrome-extension:// URL, the extension ID is read and identified, (2) a no-cors HEAD fetch to detect network-level timeouts, (3) a script-tag probe that fires when any server responds. No external proxies are used — all detection happens inside your browser, so results accurately reflect what your current extensions and network actually block.
